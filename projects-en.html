I created a CS2-themed website. Here's what I did:

Built: FastAPI, JWT, password hashing, profiles, inventory, skins, leaderboard.
Tested: IDOR, access to other users' skins, race conditions, brute-force attacks, JWT reuse.
Fixed: ownership checks, atomic transfers, rate limiting, account locking, JWT blacklist, DB UNIQUE constraints.

In this project, I built an API with users, profiles, and skins, and then started testing its security.

I checked whether it was possible to access other users' data through user_id or skin_id. I found this issue and added ownership checks.

I also tested skin transfers and simultaneous requests. I added protection against duplicate transfers and race conditions.

I also tested authentication by sending many incorrect passwords and trying to use JWT after logout. I added rate limiting, account locking, and a JWT blacklist.

In the end, I first built the API, then found several security issues myself and fixed them.
