My Journey in the World of Programming

Matvey Podolyan

1. About Me

I am a developer and writer. I work with JavaScript, studying coding, web development and cybersecurity. Previously I worked with Python. Now I am just starting my path as a developer and programmer, but my goal is to become an expert in my field. My life goal is to make technology simple to understand and interesting to study. You can explore my GitHub and my work here: GitHub.

2. First Steps in Programming

On April 14, 2026, my father recommended that I study code and create websites. He showed me examples of cool websites that I could also make. This inspired me to start learning programming. At first, I familiarized myself with basic concepts: tags, prefixes and other fundamentals. I had many trials, attempts and failures, but I continued to learn and over time began to understand how everything works.

3. Learning HTML and CSS

When I started learning style.css, it became much easier for me to work with code. I no longer needed to constantly copy and paste the same code over and over — this helped me greatly in website development.

4. Transitioning to JavaScript

The next step was learning JavaScript and connecting JS files to the site. Initially I didn't understand how it worked, but later realized it was simply a way to connect code to website pages. This seemed very cool to me because I could write code in one place, and it would work immediately on all pages of the website.

5. Creating Two Versions of the Website

Later, I started creating copies of my pages in English. This proved to be a challenging task, as I had to:

  • translate all the text,
  • understand how the website structure works,
  • adapt the pages for the different language.

But I managed to do it, and now I have two versions of my website:

  • Russian,
  • English.

6. New Skills and Development

After some time, I started learning new concepts and important elements of web development:

  • Footer,
  • Menu,
  • Working with images,
  • Various useful tips for beginners.

These skills helped me better understand the structure of modern websites and improve my projects.

My Results

After 2–3 weeks of learning, I achieved significant progress for myself and began to feel confident in my knowledge. I intend to continue my journey in the world of programming, because it is really very interesting for me.
